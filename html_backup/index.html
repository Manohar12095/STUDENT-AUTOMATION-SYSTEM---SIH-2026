⚡ Features

Everything you need for secure access

Engineered with enterprise-grade security and a user-first experience.

🤖

AI Face Verification

4-angle face capture with 128D embeddings. Cosine similarity matching with liveness detection prevents photo spoofing.

📧

Email OTP Security

Time-limited 6-digit OTPs with rate limiting, attempt tracking, and automatic cooldown after failed tries.

📊

Activity Monitor

Persistent live camera widget classifies presence states — Active, Idle, or Drowsy — with full consent controls.

🔐

Multi-Step Auth

Three-layer verification: password → face match → OTP. Each layer independently blocks unauthorized access.

🛡️

Privacy-First Design

Embeddings, not raw images. Explicit consent. Data deletion rights. On-device processing keeps video off the server.

⚙️

Session Management

View active sessions, revoke access from anywhere, auto-expire sessions, and full login audit trail.
